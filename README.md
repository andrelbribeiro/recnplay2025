CONTEXTO

O mercado de trabalho em Pernambuco passa por transformações, com destaque para a demanda por profissionais na construção civil e na confecção. Para atender a essa necessidade, desenvolvemos uma aplicação de visualização de dados que conecta vagas de emprego a candidatos de municípios com baixo IDHM e próximos aos pólos econômicos do estado.

OBJETIVO

Capacitar os participantes a construírem aplicações web interativas para visualização de dados, utilizando a biblioteca Streamlit em Python, com foco na criação de soluções acessíveis, humanas e inovadoras. 
Ao final do curso, os participantes serão capazes de importar conjuntos de dados, desenvolver visualizações dinâmicas e publicar aplicações na web, promovendo a democratização do acesso à informação.
